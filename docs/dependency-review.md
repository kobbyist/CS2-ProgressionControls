# Dependency review, 2026-09-14

The Node baseline is now **24.x**. It is the newest LTS line in the
[official release schedule](https://github.com/nodejs/Release#release-schedule).
`.node-version` selects that major in CI, and both npm and `verify.ps1` reject
other majors. CI can receive Node 24 servicing updates without changing the
project's supported major. Local validation uses Node 24.21.0.

This review covers the direct npm packages, their resolved dependency tree,
the four test-project NuGet references, production NuGet dependencies, the
.NET SDK, and the existing GitHub Actions pins. Versions below are a dated
snapshot, not an instruction to upgrade to every future `latest` release.

The latest stable typescript-eslint is 8.70.0. Its manifest range is now
`^8.70.0`, allowing compatible 8.x updates while `npm ci` uses the lockfile.
TypeScript 6.0.3 is the newest stable compiler compatible with that release.

## Validation

- Clean `npm ci`, npm dependency-tree checks, and npm audit.
- Formatting, typed ESLint, TypeScript declaration checking, and production UI build.
- All 141 Core tests, including data-driven cases after the attribute migration.
- Coverlet produced a Cobertura report through the existing VSTest runner.
- NuGet vulnerability checks included transitive dependencies for the test and
  production projects and reported no known vulnerable packages.
- The SVG and license output match the previous build byte for byte. CSS matches
  after normalizing equivalent white color notation. JavaScript output changed
  with the compiler/bundler updates and still needs the normal in-game UI check.
- The subsequent TypeScript 6.0.3 and bundler-resolution migration preserves all
  generated assets byte for byte compared with the TypeScript 5.9.3 build.

These checks do not replace in-game acceptance. No deployment was performed.
